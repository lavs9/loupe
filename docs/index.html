Press ⇧⌘Space from any app, type what you remember, and there it is — including photos that still live on a disk in your bag.

The disk carries the index.

Other search apps index this Mac. Loupe writes the catalog on the volume next to the photos, in a hidden folder named .photo_index. Unplug the HDD and that catalog leaves with it. Plug the same disk into another Mac running Loupe and search continues. Nothing is copied off the drive. No re-index.

Ready in three steps.

No account. The first search downloads the on-device model (about 865 MB, once).

  1. Install it

    Download the pkg, right-click, choose Open. Loupe sits in the menu bar. No Dock icon.

  2. Add a folder, or plug in a disk

    Settings → Add folder for this Mac. On a plugged-in HDD, Choose folder so a directory is indexed instead of the whole volume. The catalog is written in that folder.

  3. Search

    ⇧⌘Space, describe a photo. Return opens it. ⌘Return shows it in Finder.

Questions?

How is this different from search that only looks at this Mac?

Those apps keep the index on the computer. Loupe writes the index on the disk next to the photos. Plug that HDD into another Mac running Loupe and the same catalog is searched, with no re-index. That is the point.

What happens when I unplug the drive?

That disk is skipped. Search keeps running on every folder that is still here. Plug it back in and it joins again.

How is this different from Spotlight?

Spotlight finds files by name and the words in them. Loupe finds a photo by what’s in the frame, and it searches a plugged-in disk that already has an index.

Is Loupe free?

Yes. The source is on GitHub. No subscription, no account, no ads.

Which Macs does it work on?

Apple Silicon (M1 or newer), macOS 14 Sonoma or later. Not Intel. Not Windows or Linux in this version.

Do my photos get uploaded?

No. Search and index run on this Mac. The only download is the AI model the first time, and an optional update check that sends nothing about photos.

Why does the first search download 865 MB?

That’s EmbeddingGemma 2, the on-device model that understands photos and the words you type. It downloads once into Application Support. A copy is also written onto each disk you index, so the drive carries the model.

macOS says the installer can’t be opened.

This first pkg is unsigned. Right-click the file, choose Open. A signed, notarized installer is next.

Can it search the Photos app library?

Not yet. Export from Photos into a folder, or wait for PhotoKit. The Photos library package is skipped on purpose.

How do I uninstall it?

Quit Loupe from the menu-bar icon, drag Loupe.app to the Trash, and delete ~/Library/Application Support/loupe if you want the model gone too. Catalogs on your disks stay in .photo_index until you remove them.
