What it is

A local, privacy-first, portable app — so you don’t have to dig through your memories.

Why Loupe

Photos searches the library. Spotlight searches names. Loupe searches everywhere you keep pictures, clips, and songs — including an external hard disk.

Any folder Photos, RAW, audio, and video. Choose the folders to search. Skip what you don’t want.
On the go Search that travels with you. Connect the disk to another Mac, install Loupe, start searching.
All local, no cloud Nothing goes to the cloud. Everything is local. Privacy first.

The solution

Your search lives on the hard drive, next to the files.

Other apps keep search on the computer. Loupe keeps it with your pictures, clips, and songs. Unplug the drive and search goes with them. Plug that disk into another Mac, install Loupe, and you’re searching again. You don’t start over.

How it works

  1. This Mac

    Add a folder. Press ⇧⌘Space. Type a wet street, a piano take, a kitchen at night.

  2. Plug in a disk

    Choose a folder on that drive. Search for those files now lives on the drive.

  3. Another Mac

    Plug the same disk in. Install Loupe. Search. You don’t index again.

How it moves

One drive. Two desks.

Search on the first Mac. Walk the disk across the room. Search on the second. You don’t start over.

Private

Nothing leaves your system.

Photos, clips, and songs stay on the folder or disk you chose. Search runs here. The model runs here — on this Mac, or from the copy already on the HDD. No account. No cloud. Queries, thumbnails, and files are never sent out. Ever.

Get it

Three steps.

  1. Install

    Open the disk image, drag Loupe to Applications. Right-click Open until a signed download ships. First launch downloads an on-device model once, about 530 MB.

  2. Add a folder, or a disk

    Settings → Add folder on this Mac. On an HDD, Choose folder so the catalog lands next to those files.

  3. Search

    ⇧⌘Space. Return opens the file. ⌘Return shows Finder.

Questions

How is this different from search that only looks at this Mac?

Photos searches the Photos library only. Spotlight searches names only. Loupe searches everywhere you keep pictures, clips, and songs, including an external hard disk. Choose the folders you want. Skip the rest.

What files does it search?

Photos and RAW. Songs: mp3, m4a, aac, wav, aiff, flac, ogg. Clips: mp4, m4v, mov, avi, mkv, webm, mpeg, 3gp. One hit per file.

What does the first launch download?

An on-device model, about 530 MB, once. The app itself is a small download. The model stays on this Mac. If you index a disk, a copy goes on that disk too.

What happens when I unplug the drive?

That disk is skipped. Folders still on this Mac keep searching. The files and the search for them live on the drive. On the next machine: install Loupe, plug the same disk in, search. You don’t start over.

Do my photos get uploaded?

No. Nothing leaves your system. Photos, clips, and songs stay on the folder or disk you chose. Search runs here. The model runs here — on this Mac, or from the copy already on the HDD. There is no account and no cloud. Queries, thumbnails, and files are never sent out. Ever.

macOS says the installer can’t be opened.

This first download is unsigned. After you drag Loupe to Applications, right-click the app, choose Open.

Can it search the Photos app library?

Not yet. Export to a folder, or wait for PhotoKit.
