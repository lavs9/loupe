Matching files come back from this Mac and from any disk you plug in that already holds an index.

The catalog lives next to the pictures, in a folder named .photo_index. Unplug the disk and that catalog leaves with it. Plug the same disk into another Mac running Loupe and search continues. Nothing is copied off the drive. Nothing about the photos is sent to a server.
