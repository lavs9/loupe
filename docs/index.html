What it is

A loupe for every folder you keep photos in.

Photos.app searches the Photos library. Spotlight searches names. Loupe searches what’s in the frame — in any folder on this Mac, on a plugged-in HDD or SSD, or across a whole volume you choose. ⇧⌘Space, from the menu bar.

Any folder or an entire disk
On the drive the index travels with the photos
On this machine the model never leaves
16 GB the Mac it was sized for

The solution

The catalog lives on the disk.

Search apps keep the index on the computer. Loupe writes it next to the photos, in a hidden folder named .photo_index.

Unplug the HDD and that catalog leaves with the pictures. Plug the same disk into another Mac running Loupe and search continues. Install Loupe, connect the disk. No copy off the drive. No re-index.

Questions

How is this different from search that only looks at this Mac?

macOS photo search lives inside the Photos app library. Loupe does not stop there. You add any folder on this Mac, or a folder on a plugged-in disk, or the whole volume. The index is written next to those files, on that disk, so it is not trapped on one computer.

What happens when I unplug the drive?

That disk is skipped. Search keeps running on every folder that is still here. The photos, the index, and the model all live on the drive itself, in a hidden .photo_index folder. That is why it works on the next machine: install Loupe, plug the same disk in, and search. No re-index. No copy off the drive.

Do my photos get uploaded?

No. Nothing leaves your system. Photos stay on the folder or disk you chose. Search runs here. The model runs here — on this Mac, or from the copy already on the HDD. There is no account and no cloud. Queries, thumbnails, and pictures are never sent out. Ever.
