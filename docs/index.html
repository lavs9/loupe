What it is

A local, privacy-first, portable app — so you don’t have to dig through your memories.

Why Loupe

Photos searches the library. Spotlight searches names. Loupe searches everywhere you keep pictures — including an external hard disk.

Any folder Choose the folders to search. Skip what you don’t want.
On the go Search that travels with you. Connect the disk to another Mac, install Loupe, start searching.
All local, no cloud Nothing goes to the cloud. Everything is local. Privacy first.

The solution

Your search lives on the hard drive, next to the photos.

Other apps keep search on the computer. Loupe keeps it with your pictures. Unplug the drive and search goes with them. Plug that disk into another Mac, install Loupe, and you’re searching again. You don’t start over.

How it works

  1. This Mac

    Add a folder. Press ⇧⌘Space. Type a wet street, a blue cap, a kitchen at night.

  2. Plug in a disk

    Choose a folder on that drive. Search for those photos now lives on the drive.

  3. Another Mac

    Plug the same disk in. Install Loupe. Search. You don’t index again.

How it moves

One drive. Two desks.

Search on the first Mac. Walk the disk across the room. Search on the second. You don’t start over.

Get it

Three steps.

  1. Install

    Open the disk image, drag Loupe to Applications. Right-click Open until a signed download ships.

  2. Add a folder, or a disk

    Settings → Add folder on this Mac. On an HDD, Choose folder so the catalog lands next to those photos.

  3. Search

    ⇧⌘Space. Return opens the file. ⌘Return shows Finder.

Questions

How is this different from search that only looks at this Mac?

Photos searches the Photos library only. Spotlight searches names only. Loupe searches everywhere you keep pictures, including an external hard disk. Choose the folders you want. Skip the rest.

What happens when I unplug the drive?

That disk is skipped. Folders still on this Mac keep searching. The pictures and the search for them live on the drive. On the next machine: install Loupe, plug the same disk in, search. You don’t start over.

Do my photos get uploaded?

No. Nothing leaves your system. Photos stay on the folder or disk you chose. Search runs here. The model runs here — on this Mac, or from the copy already on the HDD. There is no account and no cloud. Queries, thumbnails, and pictures are never sent out. Ever.

macOS says the installer can’t be opened.

This first download is unsigned. After you drag Loupe to Applications, right-click the app, choose Open.

Can it search the Photos app library?

Not yet. Export to a folder, or wait for PhotoKit.
